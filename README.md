## 项目介绍

SiSeNote（四色笔记）是一款结构化笔记与复习工具。

它不仅帮助你记录知识，还帮助你建立知识结构、标记重点内容，并将记录下来的知识直接用于复习。

本仓库是四色笔记官方原创模板与精选笔记展示项目。

我们持续整理实用的学习模板和高质量原创知识笔记，让更多人了解四色笔记，也让知识整理和复习变得更加简单。

## 核心特色

### 1. 四色标注

使用四种固定颜色区分不同类型的知识：

| 颜色 | 含义 | 使用场景 |
|---|---|---|
| 🔴 红色 | 重点 / 考点 | 核心知识、重要结论 |
| 🔵 蓝色 | 概念 / 定义 | 基础概念、定义和原理 |
| 🟢 绿色 | 思路 / 答案 | 解题过程、分析方法 |
| 🟡 黄色 | 易错 / 待记 | 易错点、注意事项 |
| ⚫ 黑色 | 普通内容 | 补充说明、一般正文 |

### 2. 结构化知识整理

通过文件夹、文档和多级标题组织知识，从零散记录逐步建立完整的知识体系。

### 3. 思维导图

通过知识层级呈现内容结构，帮助快速理解知识之间的关系。

### 4. 挖空自测

使用蒙住内容的方式进行主动回忆，将笔记从单纯记录转化为复习工具。

### 5. 只看与蒙住

根据复习需要过滤不同颜色的内容，隐藏部分信息，帮助自己进行针对性复习。

## 如何使用

### 方法一：直接浏览

在 GitHub 中打开 Markdown 文件即可阅读文档内容。

### 方法二：复制到四色笔记

推荐使用项目的在线展示页面：

1. 打开一篇模板或精选笔记。
2. 点击页面中的「复制到四色笔记」按钮。
3. 打开四色笔记 APP 或 Web。
4. 创建一个新文档。
5. 在编辑区域粘贴内容。
6. 根据需要修改和补充自己的知识。

复制功能优先提供富文本格式，同时保留纯文本兼容方案。

具体颜色和格式能否完整保留，以实际粘贴效果为准。
