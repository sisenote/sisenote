# 提取练习

很多人以为记忆就是「把知识存进脑子」，于是反复往里塞。但认知心理学有个反直觉的结论：真正决定你能否用到的，不是存了多少，而是提取通道练得顺不顺。提取练习就是把「取出来」这件事本身当作训练。

## 一、定义与原理

<span class="sn-blue" data-sisenote-color="blue">概念：提取练习指在没有任何提示或仅有少量线索时，主动从长时记忆中重建信息的过程。</span>

<span class="sn-red" data-sisenote-color="red">重点：提取不是中性的「检查」，它本身就会改写和加强记忆。</span>

每次成功提取都会让这条通路更粗；即使提取失败，随后看到正确答案也能显著改善下次表现——前提是你必须先努力尝试过。

## 二、三种形式与做法

<span class="sn-green" data-sisenote-color="green">① 自由回忆：无任何线索，如空白纸复现，写出某主题的全部要点；② 线索回忆：给部分提示（首字母、公式前项）补全；③ 再认：从选项中辨别，强度最弱。优先练自由回忆，再练线索回忆。</span>

操作要点：先独立输出，再对照修正，把遗漏处标记为下一轮的目标。

## 三、使用场景与易错提醒

### 1. 适用场景

考前的「空白纸复现」、复盘时关键信息重建、口述汇报前要点提取。四色笔记的挖空自测就是典型的提取练习。

### 2. 易错点

<span class="sn-yellow" data-sisenote-color="yellow">易错一：用「看着眼熟」代替「能写出来」，把再认当成掌握。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错二：提取时频繁看提示，等于把自由回忆降级成再认。</span>

易错三：提取完不修正，错误版本被反复强化。

## 四、自测小题

不看书，用一张空白纸写出「提取练习的三种形式」，按强度从高到低排列，并各举一个学习场景。

> <span class="sn-green" data-sisenote-color="green">提示：自由回忆（空白纸写出某章要点）＞线索回忆（给出首字母补全单词）＞再认（做选择题）。强度越低越省力，但长期效果也越差。</span>

## 五、总结

<span class="sn-red" data-sisenote-color="red">记忆的关键不在「存」，而在「取」：提取通道越练越顺，知识才真正可用。</span>把空白纸复现纳入日常复习，比多读几遍书有效得多。
