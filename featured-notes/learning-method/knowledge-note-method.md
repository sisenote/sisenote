# 四色知识笔记法

记笔记不是把内容抄一遍，而是<strong>把知识整理成能用来复习的结构</strong>。四色笔记法用固定的颜色语义给每类知识分工，让一篇笔记同时承担「记录」和「复习」两种职责。

## 一、四种颜色如何分工

<span class="sn-blue" data-sisenote-color="blue">蓝色 · 概念与定义</span>：回答「这是什么」。名词解释、基础原理、公式含义都归到蓝色。

<span class="sn-red" data-sisenote-color="red">红色 · 重点与考点</span>：回答「什么最重要」。核心结论、高频考点、必须掌握的内容用红色。

<span class="sn-green" data-sisenote-color="green">绿色 · 思路与答案</span>：回答「怎么想出来」。解题步骤、分析过程、解决方案用绿色。

<span class="sn-yellow" data-sisenote-color="yellow">黄色 · 易错与待记</span>：回答「哪里容易错」。易错点、注意事项、需要反复记忆的细节用黄色。

黑色正文负责把以上内容串成连贯叙述，不需要每一段都上色。

## 二、完整使用流程

### 1. 先搭结构，再填内容

用文件夹和多级标题搭出知识框架：<span class="sn-green" data-sisenote-color="green">先有骨架，再往里填概念、重点和思路</span>。避免一上来就逐段抄写。

### 2. 只给关键内容上色

- <span class="sn-red" data-sisenote-color="red">原则：颜色是稀缺资源，只标真正重要的内容</span>
- 一篇笔记里红色内容通常不超过全文的两成，否则重点会被稀释

### 3. 用思维导图看全局

把章节层级整理成思维导图，<span class="sn-blue" data-sisenote-color="blue">在结构层面理解知识点之间的关系</span>，先看森林再看树木。

### 4. 用挖空自测做复习

把关键结论遮住，主动回忆后再揭开。<span class="sn-green" data-sisenote-color="green">主动回忆比反复阅读更能加深记忆</span>。

### 5. 用「只看与蒙住」做针对性复习

按颜色过滤内容：只显示黄色易错点集中突破，或蒙住蓝色概念做定义自测。

## 三、一个最小示例

> <span class="sn-blue" data-sisenote-color="blue">概念：单调性描述函数值随自变量变化的趋势。</span>
> <span class="sn-red" data-sisenote-color="red">重点：判断单调性优先用定义法与图像法。</span>
> <span class="sn-green" data-sisenote-color="green">思路：取值 → 作差 → 定号 → 下结论。</span>
> <span class="sn-yellow" data-sisenote-color="yellow">易错：忽略定义域区间，结论写错范围。</span>

## 四、总结

四色标注的价值不在颜色本身，而在于<strong>强迫你在记录时判断知识的性质</strong>。当你决定一段内容是概念、重点、思路还是易错时，理解就已经开始了。
