# 双重编码

「一图胜千言」不只是修辞。认知心理学家佩维奥的双重编码理论指出：人脑有言语和非言语两套系统，同一信息用文字和图像两条通道同时编码，就等于存了两份、多了两条提取线索。

## 一、定义与原理

<span class="sn-blue" data-sisenote-color="blue">概念：双重编码理论认为，信息可经由言语系统（文字、语言）和非言语系统（图像、意象）分别表征，二者相互连通。</span>

<span class="sn-red" data-sisenote-color="red">重点：图像与文字配对的信息，比单一文字信息更容易记住和回忆。</span>

原因是两条通道彼此独立又互相激活：文字想不起来时，图像线索可能把你带回答案。具体概念尤其适合形成心理意象，抽象概念则需要借助流程图间接触达。

## 二、操作方法

<span class="sn-green" data-sisenote-color="green">① 把概念转成一句简短文字定义；② 为它配一张图、示意图或心理意象；③ 让图的各部分与文字要点一一对应；④ 复习时先看图复述文字，再看文字回忆图；⑤ 抽象概念用比喻或流程图间接可视化。</span>

要点是图文必须严格对应，对不上的图会制造干扰而不是帮助。

## 三、使用场景与易错提醒

### 1. 适用场景

地理结构、生物过程、机械原理、数据统计等具象内容；抽象概念可用流程图、时间轴、关系图呈现。四色笔记里配合思维导图使用效果最佳。

### 2. 易错点

<span class="sn-yellow" data-sisenote-color="yellow">易错一：配图过于精美复杂，重点被装饰淹没。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错二：图文不对应，图和文字讲的根本不是同一件事。</span>

易错三：给纯抽象概念强行配具象图，反而造成误解。

## 四、自测小题

请用双重编码的思路，设计一个记住「光合作用」的图文方案，并说明两条通道如何互相提示。

> <span class="sn-green" data-sisenote-color="green">提示：文字写「光 + 水 + 二氧化碳 → 葡萄糖 + 氧气」；图像画一片叶子，用箭头标出阳光、水和二氧化碳进入，氧气和葡萄糖产出。复习时看图复述公式，看公式回想叶片图。</span>

## 五、总结

<span class="sn-red" data-sisenote-color="red">双重编码让知识同时拥有文字与图像两条提取线索，记得更牢、取得更快。</span>图文严格对应是关键，抽象概念宁可用流程图，也不要随便配图。
