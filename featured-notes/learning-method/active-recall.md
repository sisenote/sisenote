# 主动回忆

很多人复习就是把书和笔记反复看，看得很熟却一考试就想不起来。主动回忆反其道而行：先合上材料，靠脑子把内容「取」出来，再翻书核对。这个「取」的动作，才是记忆真正变牢的关键。

## 一、定义与原理

<span class="sn-blue" data-sisenote-color="blue">概念：主动回忆指在不看原文的情况下，凭记忆复述、写出或画出已学内容，再根据反馈修正。</span>

<span class="sn-red" data-sisenote-color="red">重点：记忆的强度取决于「提取」的次数，而不是「重复阅读」的次数。</span>

依据是「提取练习效应」：每次努力回想都会强化通往该知识的神经通路，想不起来时的挣扎本身也在加深印象。读得滚瓜烂熟，不等于能凭空写出。

## 二、操作流程

<span class="sn-green" data-sisenote-color="green">① 学习：先读懂一小节；② 遮蔽：合上书或盖住笔记；③ 回忆：写下或说出要点，越具体越好；④ 核对：翻开材料逐条比对；⑤ 补漏：把没想起来的内容标出，重点重学。</span>

一次只针对一个小单元，回忆不完整也没关系，关键是坚持先「取」后「看」，而不是一上来就翻答案。

## 三、使用场景与易错提醒

### 1. 适用场景

背诵英语单词、历史事件、公式定理、专业课概念都适用。四色笔记里可用「只看与蒙住」：只显示黄色易错栏集中突破，或蒙住蓝色定义栏做定义自测。

### 2. 易错点

<span class="sn-yellow" data-sisenote-color="yellow">易错一：把「再看一遍」当成回忆，眼睛熟悉不等于大脑能取出。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错二：想不起来立刻翻答案，剥夺了大脑努力提取的机会。</span>

易错三：一次复习整章，范围太大导致回忆无法完成，最后又退回被动阅读。

## 四、自测小题

合上书，写出「主动回忆的五个操作步骤」，写完对照上文检查哪一步被你漏掉。

> <span class="sn-green" data-sisenote-color="green">提示：学习 → 遮蔽 → 回忆 → 核对 → 补漏。最容易被跳过的是「补漏」，而它恰恰决定下一次回忆能否成功。</span>

## 五、总结

<span class="sn-red" data-sisenote-color="red">主动回忆把复习从「输入」改成「输出」，短期更费脑，长期记得更牢。</span>把每次没想起来的点记进四色笔记黄色栏，下一次优先提取它们。
