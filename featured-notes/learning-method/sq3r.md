# SQ3R 阅读法

一本书从头读到尾，合上却说不出讲了什么——这是被动阅读的通病。SQ3R 阅读法用五个步骤把读书变成主动探究：先浏览全局，带着问题进入文本，读完立刻复述，最后系统复习。

## 一、定义与原理

<span class="sn-blue" data-sisenote-color="blue">概念：SQ3R 由罗宾逊在 1946 年提出，五步依次为浏览、提问、阅读、复述、复习。</span>

<span class="sn-red" data-sisenote-color="red">重点：它在阅读前就建立问题，让大脑带着「找答案」的目的去读，而不是被动接收文字。</span>

提问激活了已有知识，为后续信息提供挂钩点；复述与复习则把短时印象转成可提取的长期记忆。

## 二、五步操作

<span class="sn-green" data-sisenote-color="green">浏览：先看标题、目录、小标题、图表和首尾段，判断全书结构与重点；提问：把每个小标题改写成问题，如「间隔重复为什么有效」；阅读：带着问题细读，边读边找答案并记下要点；复述：读完一节就合上书，用自己的话回答问题；复习：当天与一周后各回顾一次笔记与问题清单。</span>

五步中「提问」与「复述」最容易被省略，却恰恰是效果最强的两步。

## 三、使用场景与易错提醒

### 1. 适用场景

教材、专著、论文、说明书等结构清晰的材料。章节越分明，小标题改写为问题就越顺畅。

### 2. 易错点

<span class="sn-yellow" data-sisenote-color="yellow">易错一：跳过浏览直接开读，缺乏全局地图，细节记不住也串不起来。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错二：提问环节敷衍，只把标题抄一遍，没有真正形成疑问。</span>

易错三：全书读完才复述，间隔太久，内容已遗忘大半。

## 四、自测小题

请用 SQ3R 的方法，为一章标题为「遗忘曲线与复习时机」的教材设计阅读流程。

> <span class="sn-green" data-sisenote-color="green">提示：浏览该章标题、图表与首尾段；把标题改写为问题「遗忘曲线说明什么、应在何时复习」；带着问题读正文并标记要点；读完合上书口述答案；当天与一周后复习问题清单。</span>

## 五、总结

<span class="sn-red" data-sisenote-color="red">SQ3R 的本质是让阅读由「被动接受」转为「主动找答案」：先有地图和问题，再有阅读。</span>把每章的问题清单存进四色笔记的蓝色概念栏，复习时就是现成的自测题。
