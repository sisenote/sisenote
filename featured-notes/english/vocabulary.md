# 英语词汇高效记忆法

背单词最忌一个一个机械重复。利用构词规律、语境和复习节奏建立长期记忆，才能记得牢、用得出。

## 一、基础概念

<span class="sn-blue" data-sisenote-color="blue">高效记忆依赖三要素：规律（词根词缀）、语境（句子与文章）、节奏（间隔重复）。孤立地背拼写和中文释义，遗忘最快。</span>

## 二、核心重点：五大方法

- <span class="sn-red" data-sisenote-color="red">词根词缀法：port（搬运）→ export（出口）、import（进口）、transport（运输），一个词根带一串词。</span>
- 语境记忆法：在句子中记词，如 The committee approved the proposal，比单背 approve 更有效。
- 分类记忆法：按主题成组记忆（食物、交通、情绪），建立语义网络。
- 主动回忆法：遮住答案自测，比反复看、反复抄更高效。
- 间隔重复法：按 1 天、3 天、7 天、15 天的间隔复习，对抗遗忘曲线。

### 1. 遗忘曲线

<span class="sn-blue" data-sisenote-color="blue">艾宾浩斯遗忘曲线表明遗忘「先快后慢」，因此复习要及时，并随记忆巩固逐步拉长间隔。</span>

## 三、分析思路

<span class="sn-green" data-sisenote-color="green">记词三步：① 理解词根词缀与构词逻辑；② 放进例句或文章里运用（造句、复述）；③ 按间隔计划复习，并用主动回忆检验效果。</span>

## 四、易错提醒

- <span class="sn-yellow" data-sisenote-color="yellow">易错一：只背拼写和中文释义，不会用。要连同发音、词性、常用搭配和例句一起记，输出一次胜过看十次。</span>
- <span class="sn-yellow" data-sisenote-color="yellow">易错二：记完就不再复习。遗忘是先快后慢的，必须及时复习；近义词如 affect/effect、rise/raise 要结合句子区分，别脱离语境。</span>

## 五、自测与小结

用词根 port 推测下列词义：export、import、transport。

> <span class="sn-green" data-sisenote-color="green">参考：export 出口（ex- 向外 + port 搬运）、import 进口（im- 向内）、transport 运输（trans- 跨越）。</span>

<span class="sn-red" data-sisenote-color="red">小结：记单词的正确姿势是「懂构词 + 进语境 + 勤复习」，三步缺一不可。</span>
