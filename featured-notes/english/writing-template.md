# 英语议论文三段式写作框架

英语议论文最怕「想到哪写到哪」。用固定的三段式框架搭好骨架，再填入地道句型，文章立刻结构清晰、论证有力。

## 一、基础概念

<span class="sn-blue" data-sisenote-color="blue">三段式结构指开头段提出观点、主体段分层论证、结尾段总结升华。它的价值在于让阅卷者一眼看清你的逻辑，也是考场作文最稳妥的框架。</span>

## 二、核心重点：各段套用句型

### 1. 开头段：引入话题 + 表明立场

- 常用句型：Nowadays, ... has become increasingly popular. / There is a widespread debate over whether ...
- 示例：Nowadays, online learning has become increasingly popular. In my view, it offers more benefits than drawbacks.

### 2. 主体段：主题句 + 论据 + 例证

<span class="sn-red" data-sisenote-color="red">重点：每个主体段都用「主题句 + 论据 + 例子」展开，段首用连接词标明层次 —— First and foremost, ... / What's more, ... / For example, ...</span>

- 示例：First and foremost, online learning is flexible. Students can watch lectures at their own pace and review difficult parts anytime.

### 3. 结尾段：总结 + 建议或展望

- 常用句型：In conclusion, ... / Taking all these factors into consideration, ...
- 示例：In conclusion, online learning is a valuable tool when used properly.

## 三、分析思路

<span class="sn-green" data-sisenote-color="green">写作四步：① 审题定观点（支持哪一方）；② 列出 2 至 3 个分论点；③ 每段按「主题句 + 论据 + 例证」展开；④ 结尾呼应开头，给出建议或展望。</span>

## 四、易错提醒

- <span class="sn-yellow" data-sisenote-color="yellow">易错一：观点前后要一致，不能开头支持、结尾反对；举例要具体，避免空泛的 For example, many people think so。</span>
- <span class="sn-yellow" data-sisenote-color="yellow">易错二：通篇简单句会显得单薄，应适当用从句和连接词提升连贯性，但必须以正确为前提；议论文主体常用一般现在时，注意时态统一。</span>

## 五、自测与小结

用三段式框架为 "Should students use smartphones at school?" 列出提纲（只写观点与分论点）。

> <span class="sn-green" data-sisenote-color="green">参考：观点——应有条件允许；分论点一——便于查资料、辅助学习；分论点二——需规则限制以免分心；结尾——在管理得当前提下有益。</span>

<span class="sn-red" data-sisenote-color="red">小结：框架负责结构，句型负责表达，二者结合，作文就有骨架也有血肉。</span>
