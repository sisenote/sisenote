# 完形填空四步解题法

完形填空同时考词汇、语法、搭配和语篇理解。很多丢分不是因为不会，而是因为只看空格所在句。按四步法做，正确率会明显提升。

## 一、基础概念

<span class="sn-blue" data-sisenote-color="blue">完形填空是在有空缺的短文中填入恰当选项，综合考查词义辨析、固定搭配、语法结构与上下文逻辑四类能力。</span>

## 二、核心重点：四大考查维度

- <span class="sn-red" data-sisenote-color="red">词义辨析：近义词区别，如 affect（动词，影响）与 effect（名词，效果）。</span>
- 固定搭配：depend on, result in, be responsible for
- 语法结构：时态、从句、非谓语、冠词
- 上下文逻辑：转折、因果、递进、对比

### 1. 复现原则

答案常在上下文中以原词、同义词或反义词形式复现。如前文出现 He was afraid，后文空格可能选与 fear 相关的词。

## 三、分析思路

<span class="sn-green" data-sisenote-color="green">四步法：① 通读全文，忽略空格先抓大意、体裁与基调；② 逐空定位，结合上下文和固定搭配先易后难；③ 逻辑验证，检查转折、因果是否通顺；④ 复读全文，把答案代入通读一遍，语感顺畅即正确。</span>

## 四、易错提醒

- <span class="sn-yellow" data-sisenote-color="yellow">易错一：只看空格所在句不联系上下文；忽略固定搭配，如 The price is too ___ 应填 high 而非 expensive。</span>
- <span class="sn-yellow" data-sisenote-color="yellow">易错二：受汉语思维干扰，如 I am used to ___ up early 应填 getting（习惯于），而 used to get 表示「过去常常」；一词多义必须看语境。</span>

## 五、自测与小结

用 get 的适当形式填空：I used to ___ up late, but now I'm used to ___ up early.

> <span class="sn-green" data-sisenote-color="green">参考：get; getting。前一空 used to do 表过去常常，后一空 be used to doing 表习惯于。</span>

<span class="sn-red" data-sisenote-color="red">小结：完形填空的答案在上下文里，先读全文再填空，切忌边读边填。</span>
