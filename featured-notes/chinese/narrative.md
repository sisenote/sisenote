# 记叙文写法要点

记叙文要写得具体、动人，靠的不是辞藻，而是把事讲清楚、把人写鲜活。这篇笔记把六要素、线索和描写方法串起来，照着检查自己的文章。

## 一、先搭好骨架

<span class="sn-blue" data-sisenote-color="blue">概念：记叙文六要素是时间、地点、人物、起因、经过、结果，其中「经过」是重点，要写得具体完整。</span>

<span class="sn-red" data-sisenote-color="red">重点：线索是贯穿全文的脉络，可以是人、物、事、情感或时间。线索清楚，文章才形散神不散。</span>

## 二、安排叙述顺序

<span class="sn-green" data-sisenote-color="green">思路：顺叙按时间先后写，条理清楚；倒叙把结局或高潮提到开头，制造悬念；插叙在叙述中插入相关回忆，补充背景、丰富形象。选择哪种顺序，看你想突出什么。</span>

## 三、把人和事写具体

<span class="sn-blue" data-sisenote-color="blue">概念：人物描写包括外貌、语言、动作、神态、心理五种；环境描写包括自然环境和社会环境，作用是交代背景、渲染气氛、烘托人物、推动情节。</span>

- 动作描写例：「他蹒跚地走到铁道边，慢慢探身下去」—— 朱自清《背影》用一连串动词，写出父亲买橘子的艰难与深情。
- 心理描写例：「我心里暗笑他的迂」—— 《背影》中「我」的心理变化，为后文的愧疚作铺垫。

## 四、详略与立意

<span class="sn-red" data-sisenote-color="red">重点：与中心关系密切的浓墨重彩，无关的惜墨如金；善用「以小见大」，通过一个细节、一件小事表现亲情、成长、责任等大主题。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错：记流水账，从早到晚平均用力；只叙事不抒情议论，结尾没有点题；人物只有「他很善良」这样的空评，没有具体事例支撑。</span>

## 五、自测

以「那一刻，我长大了」为题，列出你的六要素和一条线索。

<span class="sn-green" data-sisenote-color="green">答案示例：时间——某个雨夜；地点——医院走廊；人物——我和母亲；起因——母亲发烧；经过——我第一次独自挂号、取药、守在床边；结果——看到母亲欣慰的笑，我懂得担当。线索可设为「雨夜的伞」，前后照应，结尾点题「长大」。</span>
