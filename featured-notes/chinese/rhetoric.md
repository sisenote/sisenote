# 常见修辞手法整理

修辞赏析题几乎每份试卷都有。这篇笔记把常考修辞的定义、例句和「作用」说清楚，并给出可直接套用的答题格式。

## 一、基础概念

<span class="sn-blue" data-sisenote-color="blue">概念：修辞是为了增强表达效果而选用的语言方式；赏析题不只考「认出是什么」，更考「这样写有什么好处」。</span>

## 二、常考修辞及例句

### 1. 比喻

<span class="sn-red" data-sisenote-color="red">重点：比喻由本体、喻体、比喻词构成，分明喻（像、仿佛）、暗喻（是、成为）、借喻（只出现喻体）；作用是化抽象为具体、生动形象。</span>

- 明喻例：「问君能有几多愁？恰似一江春水向东流」（李煜《虞美人》）—— 把愁比作春水，写出愁的绵长无尽。
- 暗喻例：「你是人间四月天」（林徽因）—— 直接把对方说成四月天。

### 2. 拟人

把物当作人来写，赋予人的情感动作，使事物亲切生动。

例：「感时花溅泪，恨别鸟惊心」（杜甫《春望》）—— 花溅泪、鸟惊心，实是诗人忧国伤时的移情。

### 3. 排比与对偶

<span class="sn-red" data-sisenote-color="red">重点：排比是三个或三个以上结构相同或相近的短语、句子并列，重在增强气势；对偶是两两相对、字数相等、词性相当，重在整齐对称。</span>

- 排比例：「东市买骏马，西市买鞍鞯，南市买辔头，北市买长鞭」（《木兰诗》）—— 铺陈出办装束的紧张忙碌。
- 对偶例：「两个黄鹂鸣翠柳，一行白鹭上青天」（杜甫）—— 数量、色彩、动作两两相对。

### 4. 夸张

对事物的形象、程度作有目的的放大或缩小。

例：「飞流直下三千尺，疑是银河落九天」（李白《望庐山瀑布》）—— 突出瀑布的雄伟。

### 5. 设问与反问

<span class="sn-blue" data-sisenote-color="blue">概念：设问是自问自答，目的是引人注意、启发思考；反问是答案寓于问中、不必回答，目的是加强肯定或否定的语气。</span>

- 设问例：「问君能有几多愁？恰似一江春水向东流。」
- 反问例：「孰知赋敛之毒有甚是蛇者乎」（柳宗元《捕蛇者说》）—— 谁能想到搜刮百姓的毒害比蛇更厉害呢，答案寓于问中。

## 三、赏析答题格式

<span class="sn-green" data-sisenote-color="green">思路：三步作答——① 指出手法（比喻 / 拟人 / 排比……）；② 结合句子解释怎么用的；③ 点出表达效果或情感（生动形象地写出了……，表达了……）。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错：设问与反问常混淆——有问有答是设问，只问不答、答案在问中是反问；比喻与拟人也不同，比喻重在「喻体相似」，拟人重在「把物当人写」。</span>

## 四、挖空自测

指出例句的修辞：

1. 感时花溅泪，恨别鸟惊心。　2. 孰知赋敛之毒有甚是蛇者乎？

<span class="sn-green" data-sisenote-color="green">答案：① 拟人（兼移情于物）；② 反问。答题时记得按「手法＋解释＋情感」三步写完整。</span>
