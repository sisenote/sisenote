# 现代文学常识速记

文学常识题考的是「作家—作品—体裁」的准确对应。这篇笔记按体裁和时期梳理必记作家作品，帮你在选择题里快速排除干扰项。

## 一、时间范围与记忆方法

<span class="sn-blue" data-sisenote-color="blue">概念：中国现代文学通常指 1919 年五四运动至 1949 年新中国成立之间的文学，1949 年以后称当代文学。</span>

<span class="sn-red" data-sisenote-color="red">重点：鲁迅是本部分第一考点——小说集《呐喊》《彷徨》《故事新编》，散文集《朝花夕拾》，散文诗集《野草》，杂文集《坟》等；《狂人日记》是中国第一篇现代白话短篇小说。</span>

<span class="sn-green" data-sisenote-color="green">思路：按体裁分头记——小说、散文、诗歌、戏剧各记 2～3 位代表作家，再记其代表作，比按年代硬背更牢。</span>

## 二、代表作家作品

| 体裁 | 作家 | 代表作 |
|---|---|---|
| 小说 | 茅盾 / 巴金 | 《子夜》/《家》《春》《秋》 |
| 小说 | 老舍 / 沈从文 / 钱钟书 | 《骆驼祥子》/《边城》/《围城》 |
| 诗歌 | 郭沫若 / 徐志摩 / 艾青 | 《女神》/《再别康桥》/《大堰河——我的保姆》 |
| 戏剧 | 曹禺 / 老舍 | 《雷雨》/《茶馆》 |

## 三、当代文学要点

<span class="sn-blue" data-sisenote-color="blue">概念：当代文学中，莫言 2012 年获诺贝尔文学奖，代表作有《红高粱家族》；路遥有《平凡的世界》，余华有《活着》。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错：《朝花夕拾》是散文集，《野草》是散文诗集，二者常被调换；《女神》是郭沫若的诗集，《雷雨》是曹禺的话剧，不要张冠李戴。</span>

## 四、自测

判断下列说法是否正确：

1. 《狂人日记》选自鲁迅小说集《彷徨》。
2. 《雷雨》是曹禺的话剧，《茶馆》是老舍的话剧。

<span class="sn-green" data-sisenote-color="green">答案：① 错误，《狂人日记》选自《呐喊》；② 正确。</span>
