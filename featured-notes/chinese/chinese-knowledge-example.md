# 文言实词「之」的用法整理

文言虚词「之」出现频率极高，用法多且容易混淆。这篇笔记用四色语义把它的常见用法归纳成一张可复习的知识卡。

## 一、基础概念

<span class="sn-blue" data-sisenote-color="blue">「之」是文言文中最高频的虚词之一，主要作代词、助词和动词，具体含义要靠它在句中的位置和作用判断。</span>

## 二、用法归类

### 1. 作代词

- <span class="sn-blue" data-sisenote-color="blue">代人、代物、代事，相当于「他 / 它 / 这件事」</span>
- 例：「学而时习<span class="sn-red" data-sisenote-color="red">之</span>」—— 指代学过的知识
- <span class="sn-green" data-sisenote-color="green">判断思路：看它是否指代前文出现过的对象</span>

### 2. 作结构助词「的」

- <span class="sn-blue" data-sisenote-color="blue">放在定语和中心语之间，相当于现代汉语的「的」</span>
- 例：「水陆草木<span class="sn-red" data-sisenote-color="red">之</span>花」—— 水中陆地上草木的花

### 3. 用在主谓之间，取消句子独立性

- <span class="sn-red" data-sisenote-color="red">重点：这种用法不译，容易和「的」混淆</span>
- 例：「予独爱莲<span class="sn-red" data-sisenote-color="red">之</span>出淤泥而不染」

### 4. 作动词「到、往」

- <span class="sn-blue" data-sisenote-color="blue">后接地点名词，表示前往某地</span>
- 例：「送杜少府<span class="sn-red" data-sisenote-color="red">之</span>任蜀州」

## 三、分析思路

<span class="sn-green" data-sisenote-color="green">解题三步：① 看位置 —— 在动词后多为代词；② 看搭配 —— 在定中之间多为「的」；③ 看句意 —— 代入翻译是否通顺。</span>

## 四、易错提醒

- <span class="sn-yellow" data-sisenote-color="yellow">易错一：主谓之间的「之」常被误译成「的」，其实不必译出</span>
- <span class="sn-yellow" data-sisenote-color="yellow">易错二：作动词「到」的用法出现较少，容易被忽略</span>
- <span class="sn-yellow" data-sisenote-color="yellow">待记：结合具体句子记忆，不要脱离语境背规则</span>

## 五、挖空自测

遮住答案，说出下列句中「之」的用法：

1. 学而时习<strong>之</strong> —— <span class="sn-green" data-sisenote-color="green">代词，指代所学内容</span>
2. 水陆草木<strong>之</strong>花 —— <span class="sn-green" data-sisenote-color="green">结构助词「的」</span>
3. 予独爱莲<strong>之</strong>出淤泥而不染 —— <span class="sn-green" data-sisenote-color="green">主谓之间，取消句子独立性，不译</span>
