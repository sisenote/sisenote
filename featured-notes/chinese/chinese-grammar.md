# 现代汉语语法基础

病句题、压缩语段题都建立在语法基础上。这篇笔记把词性、短语、句子成分和六大病句类型串成一套，复习时按图索骥。

## 一、词性与短语

<span class="sn-blue" data-sisenote-color="blue">概念：词分实词和虚词。实词包括名词、动词、形容词、数词、量词、代词，能单独充当成分；虚词包括副词、介词、连词、助词、叹词、拟声词，主要起语法作用。</span>

短语的常见结构：

| 结构 | 特点 | 例子 |
|---|---|---|
| 并列 | 词与词平等联合 | 山川河流 |
| 偏正 | 修饰语＋中心语 | 美丽的花 |
| 动宾 | 动作＋对象 | 读书 |
| 主谓 | 陈述对象＋陈述内容 | 阳光明媚 |
| 补充 | 中心语＋补充说明 | 跑得快 |

## 二、句子成分

<span class="sn-red" data-sisenote-color="red">重点：句子成分口诀——主谓宾，定状补，主干枝叶分清楚；定语必居主宾前，谓前为状谓后补。</span>

<span class="sn-green" data-sisenote-color="green">思路：分析句子先抓主干。「鲁班是我国古代春秋时期一位著名的建筑工匠」，主语「鲁班」、谓语「是」、宾语「工匠」，「我国古代春秋时期一位著名的建筑」都是定语。</span>

- 主语：陈述的对象，回答「谁 / 什么」。
- 谓语：陈述主语的动作或状态，回答「怎么样 / 是什么」。
- 宾语：动作涉及的对象，回答「谁 / 什么」。
- 定语、状语、补语：分别修饰名词、修饰动词形容词、补充动词形容词的程度结果。

## 三、六大病句类型

<span class="sn-red" data-sisenote-color="red">重点：病句六大类型——语序不当、搭配不当、成分残缺或赘余、结构混乱、表意不明、不合逻辑。</span>

- 搭配不当例：「他那认真的态度和慈祥的面容浮现在我的脑海里」—— 「态度」不能「浮现」，主谓搭配不当。
- 语序不当例：「我们要及时解决并发现问题」—— 应先「发现」后「解决」。
- <span class="sn-yellow" data-sisenote-color="yellow">易错：介词开头常造成主语残缺。如「通过这次活动，使我明白了团结的重要」，「通过……使……」连用让句子没了主语，删去「通过」或「使」即可。</span>

## 四、修改原则与自测

<span class="sn-yellow" data-sisenote-color="yellow">易错：改病句要保留原意，能调不删、能删不换，不要另起炉灶把句子改得面目全非。</span>

自测：指出下列句子的病因并修改。

1. 我们要及时解决并发现问题。
2. 通过这次活动，使我明白了团结的重要。

<span class="sn-green" data-sisenote-color="green">答案：① 语序不当，改为「及时发现并解决」；② 主语残缺，删「通过」或「使」，如「这次活动使我明白了团结的重要」。</span>
