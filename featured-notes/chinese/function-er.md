# 文言虚词「而」的用法整理

「而」是文言文中最高频的连词之一，也能作代词和助词。这篇笔记按前后关系给它归类，配真实例句，翻译时照着判断即可。

## 一、基础概念

<span class="sn-blue" data-sisenote-color="blue">概念：「而」主要作连词，连接词、短语或分句，表示并列、承接、转折、递进、修饰等关系；少数情况通「尔」作代词，或附在形容词后作词尾。</span>

<span class="sn-red" data-sisenote-color="red">重点：判断「而」的含义，看它前后两部分是什么关系，而不是死记义项。</span>

## 二、作连词的五种关系

### 1. 表并列（又、并且）

前后两项地位平等，可以互换位置。

- 例：「蟹六跪<strong>而</strong>二螯」（《荀子·劝学》）—— 六条腿和两只钳。
- 例：「敏<strong>而</strong>好学」（《论语》）—— 聪敏并且好学。

### 2. 表承接（就、接着）

前后动作有先后顺序，不可互换。

- 例：「择其善者<strong>而</strong>从之」（《论语》）—— 选出他们的优点就学习。
- 例：「舌一吐<strong>而</strong>二虫尽为所吞」（沈复《童趣》）—— 舌头一吐，两只小虫就被吞掉。

### 3. 表转折（却、但是）

<span class="sn-yellow" data-sisenote-color="yellow">易错：转折是最高频也最容易漏译的用法，必须把「却 / 但是」译出来。</span>

- 例：「人不知<strong>而</strong>不愠」（《论语》）—— 别人不了解我，我却不生气。
- 例：「青，取之于蓝，<strong>而</strong>青于蓝」（《荀子·劝学》）—— 靛青从蓝草中提取，却比蓝草更青。

### 4. 表递进（而且、更）

后一层意思更进一层。例：「君子博学<strong>而</strong>日参省乎己」（《荀子·劝学》）—— 广泛学习而且每天反省自己。

### 5. 表修饰（地、着）

前项作状语，描写后项动作的状态或方式。

- 例：「吾恂恂<strong>而</strong>起」（柳宗元《捕蛇者说》）—— 小心翼翼地起身。
- <span class="sn-green" data-sisenote-color="green">思路：「而」前是形容词或状语、后面是动词时，多表修饰，译作「地」「着」或干脆不译。</span>

## 三、其他用法

<span class="sn-blue" data-sisenote-color="blue">概念：通「尔」作代词时译作「你 / 你的」；附在形容词后作词尾时译作「……的样子」。</span>

- 代词例：「某所，<strong>而</strong>母立于兹」（归有光《项脊轩志》）—— 这个地方，你母亲曾站过。
- 助词例：「杂然<strong>而</strong>前陈者」（欧阳修《醉翁亭记》）—— 杂乱地摆在面前的。

## 四、辨析步骤与易错提醒

<span class="sn-red" data-sisenote-color="red">重点：三步判断——① 看前后是词、短语还是分句；② 判断前后是平等、先后、相反还是修饰；③ 代入「又 / 就 / 却 / 而且 / 地」检验是否通顺。</span>

<span class="sn-yellow" data-sisenote-color="yellow">易错：把修饰当成并列，如「恂恂而起」不是「小心翼翼并且起身」；把转折当成并列，句意会完全相反。</span>

## 五、挖空自测

说出下列句中「而」的用法：

1. 人不知<strong>而</strong>不愠　2. 择其善者<strong>而</strong>从之　3. 蟹六跪<strong>而</strong>二螯　4. 吾恂恂<strong>而</strong>起

<span class="sn-green" data-sisenote-color="green">答案：① 转折，却；② 承接，就；③ 并列，和；④ 修饰，地。</span>
