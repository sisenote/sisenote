# 数据分析

数据分析不是堆图表，而是用数据回答业务问题。这篇笔记把分析流程、描述统计、常用方法和可视化选型整理成一张实战卡，方便复制到四色笔记里按图索骥。

## 一、标准分析流程

流程：明确问题→收集数据→清洗数据→探索分析→建模与可视化→得出结论→推动行动。

<span class="sn-red" data-sisenote-color="red">第一步永远是明确业务问题，先有问题再找数据，避免为了分析而分析</span>。

<span class="sn-yellow" data-sisenote-color="yellow">结论要能指导行动，"数据上涨了"不是结论，"因某渠道投放使转化率提升，建议加大投入"才是</span>。

## 二、描述性统计

<span class="sn-blue" data-sisenote-color="blue">集中趋势有均值、中位数、众数；均值对极端值敏感，中位数更稳健。离散程度有极差、方差、标准差、四分位距</span>。

<span class="sn-red" data-sisenote-color="red">数据清洗中常用IQR法识别异常值：低于Q1－1.5×IQR或高于Q3＋1.5×IQR的视为异常</span>。

<span class="sn-yellow" data-sisenote-color="yellow">缺失值处理要分析原因，直接删除可能引入偏差；重复值和格式不统一也要先处理</span>。

## 三、常用分析方法

<span class="sn-green" data-sisenote-color="green">方法：对比分析（同比、环比）、漏斗分析（看各环节转化率）、留存分析（次日、7日、30日留存）、分组拆解</span>。

<span class="sn-blue" data-sisenote-color="blue">RFM模型用最近消费时间、消费频率、消费金额三个维度给客户分群</span>。

相关不等于因果，两个指标一起变化可能只是巧合或受第三个变量影响。

警惕幸存者偏差和辛普森悖论，分组结论与整体相反时要检查结构差异。

## 四、可视化选型

比较用条形图，趋势用折线图，占比用饼图（类别不宜过多），分布用直方图或箱线图，相关关系用散点图。

常用指标：日活跃用户、月活跃用户、转化率、客单价、成交额、复购率。

饼图切片过多看不清，纵轴不从零开始会夸大差异，图表标题要直接写出结论。

## 五、自测小题

某电商5月成交额120万，4月100万，去年5月80万，求环比与同比增长率。

> <span class="sn-green" data-sisenote-color="green">答案：环比＝（120－100）÷100＝20%；同比＝（120－80）÷80＝50%。环比看短期变化，同比可过滤季节性因素。</span>

## 六、总结

数据分析的主线是"先问问题，再清洗核实，选对方法，结论落到行动"。工具只是手段，业务判断力才是核心。
