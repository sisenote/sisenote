# 文章写作规范（内容写手必读）

你在为「四色笔记官方模板与精选笔记」公开内容站写 Markdown 文章。目标是让读者一看就**想把内容复制到四色笔记 APP 里用**。这是唯一事实源，务必逐条遵守。

## 一、先看两篇范文（必须读）

- 模板范文：`templates/study/learning-plan.md`
- 精选笔记范文：`featured-notes/mathematics/mathematics-knowledge-example.md`

照着这个信息密度和四色标注密度写，不要更空。

## 二、文件路径与命名

按分配给你的分类目录，每篇一个 `<slug>.md`。文件名全小写英文 + 连字符，见 `docs/content-plan.md` 的选题清单。

## 三、Front Matter（严格照抄结构）

```yaml
---
layout: default
title: 文档标题
description: 一句话简介，20-40字，说清用途与收益
category: 分类中文名
tags:
  - 标签一
  - 标签二
  - 标签三
type: template
---
```

精选笔记把 `type` 改成 `featured`。`category` 用该分类中文名（见 content-plan.md 表格）。

## 四、正文结构

1. 第一行 `# 文档标题`（与 front matter 的 title 完全一致）。
2. 紧接着 1-2 句「这篇解决什么问题、怎么用」，让人产生复制冲动。
3. 用 `## 一、…` `## 二、…` 分 3-5 个主节；需要时 `### 1. …` 子节。层级清楚。
4. 结尾放「总结」或「使用建议」小节。

## 五、四色标注（关键，复制一致性的核心）

每篇 **4-8 处**，覆盖「概念/重点/思路/易错」中至少 2 类。只标关键词句，不要整段上色：

```html
<span class="sn-blue" data-sisenote-color="blue">概念：…</span>
<span class="sn-red" data-sisenote-color="red">重点：…</span>
<span class="sn-green" data-sisenote-color="green">思路：…</span>
<span class="sn-yellow" data-sisenote-color="yellow">易错：…</span>
```

- 语义：蓝=概念/定义；红=重点/考点/结论；绿=思路/步骤/答案；黄=易错/待记/提醒。
- ⛔ 不要在正文写死任何色值 hex（`#FF5555` 等）—— 颜色由站点的 `copy.js` 统一输出，你只写 class 和 data 属性。

## 六、两类文章的区别

- **`type: template`（模板）**：给用户填自己内容的骨架。必须有可填写占位：`【填写…】`、`___`、`☐`、空表格。读者复制后能直接填。但仍要有 4-8 处四色标注示范「这类内容该怎么用四色记」。
- **`type: featured`（精选笔记）**：真实、具体、可验证的知识。要有定义、步骤、例子、公式、易错点。不是空壳模板。每篇要能让读者学到至少一个具体知识点。

## 七、质量红线

- ⛔ 禁止空洞占位（「这里写内容」「待补充」「同上」）。每节都要有信息量。
- ⛔ 禁止中英文夹杂的病句（如「学习 planning」「corrected 思路」）。全中文为主，专业术语英文可保留。
- ⛔ 不含真实用户个人信息，不抄第三方教材全文。
- 适度用列表 / 表格 / 引用；表格列数 ≤4；每篇正文 400-800 字。
- 至少放一个「自测 / 使用示例 / 填表示例」增强实用性（模板放填表示例，笔记放自测题）。

## 八、色值红线

四色语义色值 = 四色笔记编辑器白名单（红 #FF5555 蓝 #005CFF 绿 #01BD33 黄 #FFCD1C）。正文只写 class/data 属性，不写 hex。

## 九、交付

写完你负责的全部分类后，报告：每个目录写了多少篇、总计多少篇、有没有跳过或复用已有文件。不要修改 `index.md`（列表页由维护者统一生成）。不要修改任何 CSS/JS/配置。
