# 头脑风暴模板

好点子常被「这不行」当场掐死。头脑风暴先用规则保护创意、批量产出，再统一筛选。照着填，你能在短时间内攒出足够多的选择，再挑出真正有价值的。

## 一、定题与规则

- 议题：【用一句话写清要解决什么，越具体越好】
- 四条规则：☐ 暂缓评判 ☐ 多多益善 ☐ 欢迎混搭 ☐ 人人平等
- <span class="sn-blue" data-sisenote-color="blue">概念：先发散后收敛，发散阶段只管数量，不评判优劣</span>

## 二、自由发散

- 点子一：【填写】
- 点子二：【填写】
- 点子三：【填写】
- 点子四：【填写】
- 点子五：【填写】
- <span class="sn-green" data-sisenote-color="green">思路：先追求数量，目标二十个起步；再奇怪的点子也先记下，可能触发新联想</span>

## 三、分类整理

| 类别 | 对应点子 | 可合并 |
|---|---|---|
| 【如：低成本】 | 【填写】 | ☐ 是 ☐ 否 |
| 【如：高影响】 | 【填写】 | ☐ 是 ☐ 否 |

- <span class="sn-red" data-sisenote-color="red">重点：这一步才开始评判，按「可行性、影响力」给点子归类打分</span>

## 四、收敛决策

- 最值得试的三个点子：【填写】
- 立即执行的一个：【填写】
- 暂不采用但值得留档的点子：【填写】
- <span class="sn-yellow" data-sisenote-color="yellow">易错：边想边评，刚冒出的点子被当场否定，创意还没长大就夭折</span>

## 五、填表示例

> 议题「提升团队周会效率」。发散：限时二十五分钟、站会、轮流主持、只讲结论、会前发材料、设立议题池……按可行性归类，选出「会前发材料加只讲结论」立即试行，下次复盘效果。

> 总结：<span class="sn-red" data-sisenote-color="red">先求量，再求质，最后求可行</span>。顺序对了，创意才不被扼杀。
