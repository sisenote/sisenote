# MECE 拆解模板

面对大问题不知从何拆起？MECE 要求分类「相互独立、完全穷尽」，既不重叠也不遗漏。照着填，你的拆解会清晰无死角，分析不再东一榔头西一棒。

## 一、明确要拆的问题

- 待拆问题：【用一句话界定范围】
- 拆解目的：【为了分析原因 / 分配任务 / 制定方案】
- <span class="sn-blue" data-sisenote-color="blue">概念：MECE = 相互独立（不重叠）+ 完全穷尽（不遗漏）</span>

## 二、选择拆解维度

| 维度 | 适用对象 | 选用？ |
|---|---|---|
| 按流程（时间先后） | 有步骤的事务 | ☐ 是 ☐ 否 |
| 按结构（组成部分） | 有形或无形的整体 | ☐ 是 ☐ 否 |
| 按要素（公式分类） | 可量化的结果 | ☐ 是 ☐ 否 |

- <span class="sn-green" data-sisenote-color="green">思路：一次只用一个维度，混用维度是分类重叠的头号原因</span>

## 三、检查是否穷尽

- 是否漏掉重要类别？☐ 有，补【填写】☐ 无
- 各类别之间是否交叉？☐ 有，合并【填写】☐ 无
- <span class="sn-red" data-sisenote-color="red">重点：加一项「其他」兜底，能快速达到穷尽，但占比过大说明拆得不好</span>

## 四、收敛为结论

- 最关键的子项：【填写】
- 下一步动作：【填写】
- <span class="sn-yellow" data-sisenote-color="yellow">易错：把「男性、女性、老人」并列，类别互相重叠，违反独立原则</span>

## 五、填表示例

> 问题「提升季度营收」。按要素拆：营收 = 流量 × 转化率 × 客单价。三个因子相互独立、相乘关系完整穷尽。分析发现流量稳步增长，转化率偏低是关键子项，于是把优化重点放在结算流程。

> 总结：<span class="sn-red" data-sisenote-color="red">不重叠、不遗漏，是拆解质量的最低标准</span>，也是最高标准。
