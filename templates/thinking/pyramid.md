# 金字塔原理模板

汇报让人听不懂，多半是结构出了问题。金字塔原理要求「结论先行、以上统下、归类分组、逻辑递进」，照着填，你的表达会立刻变得清楚。

## 一、顶部：一句话结论

- 核心结论：【用一句话说清你要表达什么】
- 受众：【说给谁听，他最关心什么】
- <span class="sn-blue" data-sisenote-color="blue">概念：金字塔顶 = 中心思想，全文都围绕它展开</span>

## 二、中层：支撑论点

| 论点 | 关键论据 | 是否支撑结论 |
|---|---|---|
| 论点一【填写】 | 【填写】 | ☐ 支撑 ☐ 无关 |
| 论点二【填写】 | 【填写】 | ☐ 支撑 ☐ 无关 |
| 论点三【填写】 | 【填写】 | ☐ 支撑 ☐ 无关 |

- <span class="sn-green" data-sisenote-color="green">思路：每个论点都要能回答「凭什么这么说」，上下之间须构成因果或总分关系</span>

## 三、底层：事实与数据

- 数据一：【填写，注明来源】
- 数据二：【填写，注明来源】
- <span class="sn-red" data-sisenote-color="red">重点：以上统下——上层是下层的概括，下层是上层的证据</span>

## 四、纵向与横向检查

- 纵向：每一层是否都在回答上一层的「为什么、怎么做到」？☐ 是 ☐ 否
- 横向：同一层各组是否相互独立、完整穷尽？☐ 是 ☐ 否
- <span class="sn-yellow" data-sisenote-color="yellow">易错：结论藏在最后，听众听完还不知道你要说什么</span>

## 五、填表示例

> 结论：建议本季度暂停投放甲渠道。论点一：转化率连续两季下滑（数据由百分之四降到百分之二）；论点二：获客成本高于其他渠道（一百二十元，其他渠道六十元）。两条论据共同支撑结论。先说结论，再摆理由。

> 总结：<span class="sn-red" data-sisenote-color="red">结论先行是金字塔的灵魂</span>，先讲结果再讲理由，沟通效率倍增。
