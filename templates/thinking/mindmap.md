# 思维导图模板

思维导图用「中心主题加放射分支」模拟大脑的联想方式，适合发散创意、梳理结构。复制到四色笔记后，按下面的层级填写，一张图就能看清全局。

## 一、确定中心主题

- 中心主题：【用一句话或关键词写清要思考的主题】
- 思考目的：【发散创意 / 梳理知识 / 解决问题】
- <span class="sn-blue" data-sisenote-color="blue">概念：导图 = 一个中心 + 若干主干 + 逐级细分的分支</span>

## 二、画出主干分支

围绕中心，列出三到六个主干方向：

| 主干 | 关键词 | 重要度 |
|---|---|---|
| 主干一【填写】 | 【填写】 | ☐ 高 ☐ 中 ☐ 低 |
| 主干二【填写】 | 【填写】 | ☐ 高 ☐ 中 ☐ 低 |
| 主干三【填写】 | 【填写】 | ☐ 高 ☐ 中 ☐ 低 |

- <span class="sn-green" data-sisenote-color="green">思路：主干用名词或疑问词，每条只放一个关键词，逼自己提炼</span>

## 三、延伸二级分支

- 主干一的细分：【填写两到三个关键词】
- 主干二的细分：【填写两到三个关键词】
- <span class="sn-red" data-sisenote-color="red">重点：分支之间用连线标注关系，如因果、对比、递进</span>

## 四、检查与精简

- 有没有游离在主题外的分支？☐ 有，删除 ☐ 无
- 每条分支能否再归纳成更少的主干？☐ 能 ☐ 否
- <span class="sn-yellow" data-sisenote-color="yellow">易错：把整句话塞进节点，导图变成压缩版文章，失去发散意义</span>

## 五、填表示例

> 中心主题「如何提升专注力」；主干为环境、方法、身体、工具。环境分支下有安静桌面、关闭通知；方法分支下有番茄钟、单任务；身体分支下有睡眠、运动。四条主干同级，二级只放关键词，一眼看清发力点。

> 总结：<span class="sn-green" data-sisenote-color="green">先发散再收敛</span>，关键词加层级关系，让思考既全面又清晰。
