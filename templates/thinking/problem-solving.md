# 问题解决模板

把「不知道从哪下手」的难题，拆成界定、归因、决策、验证四步。复制到四色笔记后，按下面的骨架逐格填写，就能得到一份可执行的问题解决方案。

## 一、界定问题

- 现状：【描述当前发生了什么，尽量用数据和事实】
- 目标：【描述希望达到的状态，可衡量】
- 差距：【目标与现状之间差多少】
- <span class="sn-blue" data-sisenote-color="blue">概念：问题的本质 = 目标状态 − 当前状态</span>

## 二、拆解成因

用「流程 / 人 / 资源 / 环境」四个角度穷举可能原因：

| 角度 | 可能原因 | 是否可控 |
|---|---|---|
| 流程 | 【填写】 | ☐ 是 ☐ 否 |
| 人 | 【填写】 | ☐ 是 ☐ 否 |
| 资源 | 【填写】 | ☐ 是 ☐ 否 |
| 环境 | 【填写】 | ☐ 是 ☐ 否 |

- <span class="sn-green" data-sisenote-color="green">思路：先穷举再收敛，不急着下结论，避免漏掉关键变量</span>

## 三、筛选方案

- 方案 A：【填写】 成本【高/中/低】 收益【高/中/低】
- 方案 B：【填写】 成本【高/中/低】 收益【高/中/低】
- <span class="sn-red" data-sisenote-color="red">重点：优先选「成本低、收益高」的方案，作为第一落点</span>

## 四、验证与复盘

- 验证动作：【填写一个最小成本的试验】
- 成功标准：【达到什么指标算解决】
- 复盘结论：【哪些假设被证实、哪些被推翻】
- <span class="sn-yellow" data-sisenote-color="yellow">易错：把「方案已执行」当成「问题已解决」，缺了验证这一步</span>

## 五、填表示例

> 以「周报总被退回」为例。现状＝连续三周被打回；目标＝一次通过；差距＝三次。成因中「流程」这一项＝未对齐模板要求（可控）。方案 A＝套用标准模板，成本低、收益高，先试。验证＝用新模板交一次，成功标准＝一次通过。

> 总结：<span class="sn-red" data-sisenote-color="red">界定清楚、归因穷举、方案可比、验证闭环</span>，问题解决才不会反复。
