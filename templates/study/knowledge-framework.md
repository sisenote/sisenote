# 知识体系整理模板

用一个统一的骨架整理任意主题：先搭框架，再填内容，最后标注重点与易错。复制到四色笔记后，把方括号替换成自己的知识即可。

## 一、主题概览

- 主题名称：[填写章节或知识主题]
- 一句话概括：<span class="sn-blue" data-sisenote-color="blue">这个主题讲的是……</span>
- 所属模块：[例如：函数 / 文言文 / 力学]

## 二、知识结构

### 1. 基础概念

- <span class="sn-blue" data-sisenote-color="blue">概念一：[名称 + 定义]</span>
- <span class="sn-blue" data-sisenote-color="blue">概念二：[名称 + 定义]</span>
- 概念之间的关系：[用一句话说明它们如何联系]

### 2. 核心重点

- <span class="sn-red" data-sisenote-color="red">重点一：必须掌握的核心结论</span>
- <span class="sn-red" data-sisenote-color="red">重点二：常考、常用的关键规律</span>

### 3. 分析思路

- <span class="sn-green" data-sisenote-color="green">遇到这类问题，先判断……再套用……</span>
- <span class="sn-green" data-sisenote-color="green">步骤：① 审题 → ② 定位知识点 → ③ 求解 → ④ 检查</span>

### 4. 易错提醒

- <span class="sn-yellow" data-sisenote-color="yellow">易错点一：[容易混淆或遗漏的地方]</span>
- <span class="sn-yellow" data-sisenote-color="yellow">待记：[需要反复记忆的细节]</span>

## 三、自测清单

- [ ] 不看笔记能否说出每个概念的定义？
- [ ] 能否独立复述核心重点？
- [ ] 易错点是否能一眼识别？

## 四、总结

> <span class="sn-red" data-sisenote-color="red">好笔记的标准：结构清楚、重点突出、能拿来复习。</span>
