# 错题复盘模板

错题的价值不在于抄一遍题目，而在于找到错因并防止再犯。每道错题按「题目 → 错因 → 正解 → 提醒」四步复盘。

## 一、错题记录

- 来源：[试卷 / 作业 / 练习册 + 日期]
- 题目简述：[用一两句话描述题目，不必抄全文]
- 涉及知识点：[填写对应知识点]

## 二、错因分析

选择最贴近的一类，并具体说明：

- 概念不清：<span class="sn-blue" data-sisenote-color="blue">哪个概念没理解？</span>
- 审题失误：<span class="sn-yellow" data-sisenote-color="yellow">漏掉了哪个条件？</span>
- 方法不会：<span class="sn-green" data-sisenote-color="green">缺哪一步思路？</span>
- 计算粗心：<span class="sn-yellow" data-sisenote-color="yellow">错在哪一步运算？</span>

本人错因：<span class="sn-red" data-sisenote-color="red">[写下最根本的一条，不要笼统写「粗心」]</span>

## 三、正确思路

- <span class="sn-green" data-sisenote-color="green">第一步：……</span>
- <span class="sn-green" data-sisenote-color="green">第二步：……</span>
- <span class="sn-red" data-sisenote-color="red">关键结论：……</span>

## 四、同类提醒

- <span class="sn-yellow" data-sisenote-color="yellow">易错：下次遇到同类题要先检查……</span>
- 关联题目：[记录 1 — 2 道同类题的出处]

## 五、复盘计划

- [ ] 3 天后重做一次
- [ ] 1 周后遮住答案自测
- [ ] 考前统一回看

> 复盘的目的不是记住这道题，而是<strong>不再犯同一类错</strong>。
