# 课堂笔记模板

上课时来不及整理、课后又看不懂自己的笔记？这份模板把一节课拆成信息、重点、疑问三段，复制后当堂填写，期末直接当复习提纲用。

## 一、课程信息

- 课程：【填写课程名称】｜日期：【填写日期】｜第【填写周次】周
- 主题：【填写本节主题，如「函数的单调性」】
- 讲师：【填写讲师姓名】｜地点：【填写教室 / 线上平台】
- <span class="sn-blue" data-sisenote-color="blue">概念：先写主题再记内容，主题是这节课的「钩子」，复习时一眼定位</span>

## 二、核心内容记录

### 1. 知识点清单

- 【填写知识点一：定义 / 定理 / 公式】
- 【填写知识点二：方法 / 步骤 / 适用条件】
- <span class="sn-red" data-sisenote-color="red">重点：老师反复强调、写在黑板角落、板书加框的内容优先记</span>

### 2. 例题与推导

- 例题【填写编号】：【抄录题干要点】
- 关键步骤：【填写解题转折点】
- <span class="sn-green" data-sisenote-color="green">思路：记「为什么这么做」而不是抄满每一步，用自己的话写转折点才记得住</span>

## 三、疑问与待办

- <span class="sn-yellow" data-sisenote-color="yellow">易错：当时没听懂的地方当场打问号，不要为了记得工整而跳过</span>
- ☐ 课后问同学 / 老师：【填写具体问题】
- ☐ 查教材补漏：【填写页码或章节】
- ☐ 24 小时内回顾一次本节笔记

## 四、填表示例

| 栏目 | 填写示例 |
|---|---|
| 主题 | 二次函数图像的平移 |
| 重点 | 左加右减、上加下减的口诀与图像对应 |
| 疑问 | 为什么左右平移是反的？课后用 f(x+1) 验证 |

> 示例只填了三格，你复制后把示例替换成自己的课即可。一节课记满 3—5 个重点就够，贪多反而抓不住主线。

## 五、使用建议

<span class="sn-green" data-sisenote-color="green">思路：课后花 5 分钟把红色重点改写成一句提问，复习时先自问再翻笔记，效果好过反复通读</span>。黄色的疑问当天清掉，别让它滚到期末变成黑洞。
