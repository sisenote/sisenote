# 思维导图笔记模板

知识点记了一堆却串不起来？思维导图用「中心—主干—分支」的层级结构，逼你思考知识点之间的关系。这份模板给出搭建顺序和检查清单，复制即用。

## 一、确定中心

- 中心主题：【填写一个具体的主题，如「光合作用的机制」】
- 适用目标：【填写用途：复习 / 讲解 / 写作提纲】
- <span class="sn-blue" data-sisenote-color="blue">概念：导图只有一个中心，主题越具体，发散出的分支才越有指向性</span>

## 二、搭建主干

围绕中心问自己「这个问题能拆成哪几大块」，先定 3—5 条主干。

| 主干 | 关键词 | 层级数 |
|---|---|---|
| 【填写主干一】 | 【填写 2—4 字关键词】 | 【填写层数】 |
| 【填写主干二】 | 【填写 2—4 字关键词】 | 【填写层数】 |
| 【填写主干三】 | 【填写 2—4 字关键词】 | 【填写层数】 |

- <span class="sn-green" data-sisenote-color="green">思路：先手写列出主干再画成图，主干用「名词 / 问题」命名，别写成整句</span>
- <span class="sn-red" data-sisenote-color="red">重点：主干之间要互斥、合起来能覆盖主题，遗漏的主干就是知识盲区</span>

## 三、填充分支

- 每条主干下挂 2—4 个关键词，用连线标出关系（因果 / 并列 / 递进）。
- 跨分支的关联用虚线连起来，这是导图的额外价值。
- <span class="sn-yellow" data-sisenote-color="yellow">易错：分支写字太多就变成线性笔记，每个节点控制在几个词以内</span>

## 四、填表示例

> 示例：中心「光合作用」→ 主干「条件 / 场所 / 过程 / 意义」→「过程」下再分「光反应 / 暗反应」→ 用虚线把「光反应」连到「条件：光」。先照此层级填，再补细节。

## 五、使用建议

画完别急着收，<span class="sn-green" data-sisenote-color="green">思路：用「能不能看着导图复述整章」来检验，复述不出的分支就是需要回炉的地方</span>。四色可以这样用：蓝写概念节点、红标高频考点、绿连逻辑关系、黄注易混点。
