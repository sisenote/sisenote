# 技能刻意练习模板

「练了很多遍却没进步」，多半是因为一直在重复已经会的部分。这份模板帮你拆出薄弱要素、设定略高于当前水平的练习目标，并用反馈记录每次改进。

## 一、技能与目标

- 目标技能：【填写技能，如「英语口语连读」】
- 当前水平：【填写可观察的描述】｜目标水平：【填写具体标准】
- 练习周期：【填写起止日期】｜每次时长：【填写分钟数】
- <span class="sn-blue" data-sisenote-color="blue">概念：刻意练习 = 明确目标 + 跳出舒适区 + 及时反馈 + 重复修正，四者缺一不可</span>

## 二、拆解练习要素

把技能拆成可单独训练的小块，逐项攻克。

| 要素 | 当前难点 | 单项练习法 |
|---|---|---|
| 【填写要素一】 | 【填写卡在哪】 | 【填写怎么单练】 |
| 【填写要素二】 | 【填写卡在哪】 | 【填写怎么单练】 |

- <span class="sn-red" data-sisenote-color="red">重点：每次只练一个要素，贪多会让注意力分散，进步反而更慢</span>

## 三、练习循环

- 设计练习：【填写今天要突破的一个具体点】
- 执行并记录：【填写次数 / 时长 / 表现】
- 获取反馈：【填写来源：老师 / 录音回放 / 对照范例】
- <span class="sn-green" data-sisenote-color="green">思路：反馈越即时越好，录一段自己弹琴 / 讲英语的音频回听，问题立刻浮现</span>
- <span class="sn-yellow" data-sisenote-color="yellow">易错：不要把「练了多久」当成果，要看「这个难点是否比昨天更顺」</span>

## 四、填表示例

> 示例：技能「英语连读」→ 要素「辅音+元音连读」→ 今天练「get up / pick it up 共 20 遍」→ 录音回听，目标「不卡顿」。每次只盯一类连读。

## 五、使用建议

每周回看一次练习记录，把「已经顺了的要素」移出清单，把新暴露的卡点补进来。刻意练习的关键不是意志力，而是<span class="sn-red" data-sisenote-color="red">重点：让每次练习都精准打在不会的地方</span>。
