# 自学项目规划模板

自学最容易出现「买课如山、进度为零」。这份模板把自学当项目来做：定目标、选资源、拆里程碑、设验收，让没有老师盯的学习也能自己推进到终点。

## 一、项目目标

- 自学主题：【填写主题，如「从零学数据分析」】
- 起止时间：【填写日期】｜每周投入：【填写小时数】
- 完成标准：【填写可验证的产出，如「独立完成一份数据报告」】
- <span class="sn-blue" data-sisenote-color="blue">概念：自学要先定「完成长什么样」，再用产出倒推要学什么，别以「学完某本书」为目标</span>

## 二、资源与路径

| 资源类型 | 具体资源 | 用法 |
|---|---|---|
| 主教材 / 课程 | 【填写名称】 | 【通读 / 跟练】 |
| 练习材料 | 【填写题库 / 项目】 | 【边学边做】 |
| 交流渠道 | 【填写社区 / 社群】 | 【提问答疑】 |

- <span class="sn-red" data-sisenote-color="red">重点：资源控制在三份以内，贪多会导致每份都只看个开头</span>
- <span class="sn-green" data-sisenote-color="green">思路：路径按「基础→核心→实战」三段排，每段都有可交付的小作品</span>

## 三、里程碑

| 阶段 | 时间 | 交付物 | 完成 |
|---|---|---|---|
| 基础 | 【填写】 | 【填写笔记 / 习题】 | ☐ |
| 核心 | 【填写】 | 【填写小项目】 | ☐ |
| 实战 | 【填写】 | 【填写完整作品】 | ☐ |

- <span class="sn-yellow" data-sisenote-color="yellow">易错：别把里程碑定成「看完第几章」，要看有没有产出可展示的东西</span>

## 四、填表示例

> 示例：目标「独立完成数据报告」→ 主教材《利用 Python 进行数据分析》→ 里程碑「第 4 周清洗一份公开数据，第 8 周产出图表报告」。照此把每阶段交付物写实。

## 五、使用建议

每周固定时间对照里程碑打卡，落后就砍资源、保交付，别靠延长战线硬撑。<span class="sn-green" data-sisenote-color="green">思路：自学成果要对外可见，把报告 / 作品发出去接受反馈，比闷头学好得多</span>。
