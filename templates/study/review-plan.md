# 阶段复习计划模板

距离考试还有几周，内容多到不知从哪开始？这份模板先划分范围、再排每天任务，把大块内容切成可打勾的小格，复习进度一目了然。

## 一、复习范围与目标

- 阶段：【填写第几阶段】｜时间：【起始日期】—【结束日期】
- 范围：【填写章节或知识点清单】
- 目标分数 / 掌握程度：【填写可量化目标】
- <span class="sn-blue" data-sisenote-color="blue">概念：复习计划的核心是「范围—任务—检验」三件事闭环，缺一不可</span>

## 二、内容优先级

用过往作业和错题给内容分级，先攻薄弱项。

| 等级 | 内容 | 依据 |
|---|---|---|
| A 优先 | 【填写薄弱章节】 | 【填写：错题集中 / 分数低】 |
| B 次优 | 【填写中等章节】 | 【填写：掌握不牢】 |
| C 巩固 | 【填写已掌握章节】 | 【填写：正确率高】 |

- <span class="sn-red" data-sisenote-color="red">重点：A 类内容占复习时间的 60% 以上，不要把时间平均分配</span>

## 三、每日安排

| 日期 | 复习内容 | 检验方式 | 完成 |
|---|---|---|---|
| 【填写日期】 | 【填写章节】 | 【自测 / 默写 / 限时题】 | ☐ |
| 【填写日期】 | 【填写章节】 | 【自测 / 默写 / 限时题】 | ☐ |
| 【填写日期】 | 【错题回顾】 | 【重做错题】 | ☐ |

- <span class="sn-green" data-sisenote-color="green">思路：每格写清「看什么 + 怎么验」，只写「看第三章」等于没安排</span>
- <span class="sn-yellow" data-sisenote-color="yellow">易错：别把计划排满，每天留 20% 机动时间补未完成项</span>

## 四、填表示例

> 示例：A 优先 = 函数导数（错题 12 道），每日安排「周一重做导数错题 + 限时 15 分钟检验」。先照这个颗粒度填，再逐格打勾。

## 五、使用建议

<span class="sn-green" data-sisenote-color="green">思路：每晚在表格末尾加一行「今日实际完成」，三天后就能看出计划是否过重，及时调整</span>。阶段结束时把 A 类内容重新自测一遍，确认薄弱项真的补上。
