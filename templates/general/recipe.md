# 菜谱模板

试做一道好菜，不记下来下次就忘了。这个模板把食材用量、步骤顺序和翻车心得固定下来，照着做就能复刻。复制到四色笔记，边做边补，慢慢攒出一本私家菜谱。

## 一、菜品信息

- 菜名：【填写】
- 口味：【填写，如：清淡、微辣】｜耗时：【填写】
- 份量：【填写几人份】
- <span class="sn-blue" data-sisenote-color="blue">概念：菜谱的灵魂是「可复刻」，所以用量要写清单位，比如「盐 3 克」而非「少许」</span>

## 二、食材清单

| 食材 | 用量 | 是否必备 |
|---|---|---|
| 【填写】 | 【填写】 | ☐ |
| 【填写】 | 【填写】 | ☐ |
| 【填写】 | 【填写】 | ☐ |

- <span class="sn-red" data-sisenote-color="red">重点：把「必备」和「可选」分开，缺了可选调料也能做，减掉买菜时的犹豫</span>

## 三、步骤顺序

1. 备菜：【填写处理食材的方法】
2. 烹饪：【填写火候与时间】
3. 调味：【填写下调料时机】
- <span class="sn-green" data-sisenote-color="green">思路：按「备菜—烹饪—调味—装盘」分步，每步只写关键动作，执行时一眼能扫到</span>

## 四、翻车心得

- <span class="sn-yellow" data-sisenote-color="yellow">易错：火候是家常菜翻车重灾区，写清「大火收汁几分钟」比「炒到合适」有用得多</span>
- <span class="sn-yellow" data-sisenote-color="yellow">待记：第一次做就记下调整点，比如「下次盐减半」，第二次直接改过来</span>

## 五、填表示例与使用建议

> 番茄炒蛋，咸鲜口，15 分钟，两人份。食材：番茄 2 个、鸡蛋 3 个、糖 3 克、盐 2 克。步骤：蛋液打散炒至凝固盛出；番茄炒软出汁后回锅合炒。心得：加一点糖能压酸味，下次番茄可去皮，口感更好。

> 建议：做完趁热补两笔心得，下次照着做就有底气。
