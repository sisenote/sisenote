# 面试准备模板

面试拼的不是临场发挥，而是准备密度。这份模板把公司研究、个人故事、必问清单提前备好，让你面对追问也能答得具体。复制到四色笔记后替换【】内容即可。

## 一、公司与岗位研究

- 公司业务：【主营业务 / 产品 / 近期动态】
- 岗位要求：【招聘说明里的 3 个核心能力】
- 我能匹配的点：【对应经历】
- <span class="sn-blue" data-sisenote-color="blue">概念：面试是双向匹配，研究公司是为了把你的经历翻译成对方听得懂的语言</span>

## 二、核心故事库

| 故事主题 | 背景与任务 | 我的行动与结果 |
|---|---|---|
| 【最有成就感的事】 | 【】 | 【】 |
| 【一次失败或冲突】 | 【】 | 【】 |
| 【带项目或带团队】 | 【】 | 【】 |

- <span class="sn-red" data-sisenote-color="red">重点：每个故事按「背景—任务—行动—结果」讲，结果一定要有数字或明确变化</span>

### 填表示例

> 冲突故事：与研发对排期有分歧 → 我拉齐双方目标，列出两个方案的代价 → 采纳折中方案，按期上线且未加班。

## 三、追问预案

- 弱点追问：【真实不足 + 正在改的动作】
- 离职原因：【正向表述，不吐槽前公司】
- <span class="sn-green" data-sisenote-color="green">思路：把最怕被问的 3 个问题写下来，逐一准备具体回答，现场就不会慌</span>

## 四、我要问对方

- ☐ 【团队构成 / 考核方式】｜☐【这个岗位半年内的期望】
- <span class="sn-yellow" data-sisenote-color="yellow">易错：不要问「加班多吗」这类能靠搜索引擎解决的问题，要问能判断岗位是否适合你的问题</span>

## 五、使用建议

> 面试前一晚只看这份模板，不再临时刷经验帖。把故事讲顺，比背十篇面经更有用。
