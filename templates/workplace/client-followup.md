# 客户跟进模板

跟进客户最怕「聊完就忘、下次从头寒暄」。这份模板把客户画像、每次沟通的结论和下一步动作记清楚，让你每次联系都有明确目的。复制到四色笔记后替换【】内容即可。

## 一、客户档案

- 客户 / 联系人：【公司 + 姓名 + 角色】
- 核心诉求：【他真正想解决的问题】
- 决策链：【谁使用 / 谁影响 / 谁拍板】
- <span class="sn-blue" data-sisenote-color="blue">概念：先分清「使用者」和「决策者」，对不同角色要讲不同的重点</span>

## 二、跟进记录

| 日期 | 沟通方式 | 结论与下一步 |
|---|---|---|
| 【】 | 【电话 / 会面 / 邮件】 | 【】 |
| 【】 | 【电话 / 会面 / 邮件】 | 【】 |

- <span class="sn-red" data-sisenote-color="red">重点：每次记录结尾都要有「下一步动作 + 时间」，没有下一步的跟进等于没跟进</span>

### 填表示例

> 3/5 电话：确认预算 20 万，决策人是总监 → 下一步：3/8 前发定制方案并约演示。3/9 会面：演示顺利，关注数据安全 → 下一步：3/12 提供合规材料。

## 三、机会与风险

- 当前阶段：【初步接触 / 方案沟通 / 商务谈判】
- 成交概率：【高 / 中 / 低】
- 风险点：【竞品 / 预算 / 时机】
- <span class="sn-green" data-sisenote-color="green">思路：把大目标拆成可验证的小信号，例如「对方主动问实施周期」就是积极信号</span>

## 四、易错提醒

- ☐ 下次联系时间：【日期】｜联系方式：【】
- <span class="sn-yellow" data-sisenote-color="yellow">易错：不要只记录「已联系」，要记客户的原话和关注点，那才是下次沟通的切入点</span>

## 五、使用建议

> 跟进的节奏比话术更重要。把下次联系时间写进日历，到点就联系，让客户觉得你可靠，而不是热情一阵。
