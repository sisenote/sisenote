# PPT 大纲模板

做 PPT 最忌讳先开软件再想内容。这份模板让你先用文字把逻辑搭好：一页一个结论，整套汇报讲一件事。复制到四色笔记后替换【】内容，再照着做成幻灯片。

## 一、汇报定位

- 汇报对象：【谁在听，他们关心什么】
- 核心信息：【听完这一场，希望对方记住哪一句】
- 时长 / 页数：【分钟】｜【页】
- <span class="sn-blue" data-sisenote-color="blue">概念：PPT 是听众的工具，不是讲者的讲稿；页数原则是「一页一个观点」</span>

## 二、故事线

> 背景【为什么讲】 → 问题【要解决什么】 → 方案【怎么做】 → 证据【凭什么信】 → 行动【希望对方做什么】

- <span class="sn-red" data-sisenote-color="red">重点：先把这五步写成完整句子，连起来能读通，再拆成页面</span>

## 三、逐页大纲

| 页码 | 页面标题（写结论） | 支撑要点 |
|---|---|---|
| 1 | 【一句话结论】 | 【数据 / 图表 / 案例】 |
| 2 | 【一句话结论】 | 【数据 / 图表 / 案例】 |
| 3 | 【一句话结论】 | 【数据 / 图表 / 案例】 |

### 填表示例

> 第 3 页标题写「上线首周转化提升 18%」而不是「数据分析」；支撑：转化漏斗图、两组对比数据、一句解读。

## 四、易错提醒

- <span class="sn-green" data-sisenote-color="green">思路：每页先写标题再配内容，标题写不出结论说明这页还不该存在</span>
- <span class="sn-yellow" data-sisenote-color="yellow">易错：不要在大纲阶段纠结配色和动画，先把逻辑理顺，视觉是最后一步</span>

## 五、使用建议

> 大纲写完先试着「读」给同事听 3 分钟，对方能复述核心信息再动手做页，这样返工最少。把每页的口头补充写进备注区：大纲负责逻辑，备注负责现场发挥，两者分开才清楚。
